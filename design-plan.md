# Design plan — Central Reklame

Python deterministic selection (seed 83):
- Hero architecture: Artistic Asymmetry
- Typography: Geist
- Component architectures: Asymmetrical image bento; Pinned editorial gallery; Infinite brand marquee
- GSAP paradigms: Clip-path hero reveal + staggered text reveal; ScrollTrigger pinned horizontal gallery

AIDA:
- Navigation and Attention: minimal navigation + cinematic hero
- Interest: service showcase and editorial reference imagery
- Desire: horizontal photo gallery, process sequence, customer review quotes
- Action: WhatsApp CTA, address, map and footer

Hero math:
- H1 is wide and responsive; desktop uses 7.3vw with a 1300px max-width and a 3-line composition.
- No decorative stamp icons or spam tags.

Bento density:
- Reference imagery uses a two-cell asymmetrical grid (1.4fr / 0.8fr), no empty cells.
- Service section uses a feature image beside a continuous service list.

Label and contrast:
- No cheap section-number meta labels.
- Red and white CTA text contrast is explicit; secondary controls use high-contrast outlines.
